# News

A news website built with PHP and Laravel 10, featuring separate dashboards and functionalities for administrators and users.

## Technologies Used

- PHP 8.1+
- Laravel 10
- Livewire 3
- Laravel Sanctum
- Laravel Socialite
- Laravel OTP
- No CAPTCHA
- Eloquent Sluggable
- Laravel Charts
- Pusher
- Redis
- PHP Flasher
